# Avaliação heurística por meio de checklist dos frameworks Bootstrap e Tailwind em contexto de e-commerce
## Repositório é relativo ao meu Trabalho de Conclusão de Curso. O trabalho consiste em dois projetos open-source que serão utilizados como protótipos para realizar a avalição heurística dos frameworks CSS Bootstrap e Tailwind via checklist baseada nas 10 heurísticas de Nielsen.
## O objetivo principal é comparar e verificar qual framework CSS têm mais aplicadabilidade quanto as heurísticas de Nielsen que envolvem conceitos de usabilidade para o contexto de e-commerce. Além disso, há discussões e comentários pertinentes sobre cada framework, elecando suas vantagens e desvantagens.
