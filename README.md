# Avaliação heurística por meio de checklist dos frameworks Bootstrap e Tailwind em contexto de e-commerce
## Repositório de frameworks CSS Bootstrap e Tailwind utilizando a avalição heurística via checklist baseada nas 10 heurísticas de Nielsen.
## Este trabalho consiste em utilizar dois projetos open-source que serão utilizados como protótipos para realizar a avaliação, ambos relacionados à ecommerce. O primeiro protótipo é utilizados o framewrok Bootstrap e o segundo protótipo utilizado é o Tailwind, o objetivo principal é comparar e verificar qual framework têm mais aplicadabilidade quanto as heuristicas de Nielsen que envolvem conceitos de usabilidade. Além disso, há discussões e comentários pertinentes sobre cada framework, elecando suas vantagens e desvantagens.
